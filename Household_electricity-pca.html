1. Introduction and problem domain

Electricity use in a home changes with the time of day, the season and the appliances in use. Smart meters now record this use every minute, which gives a large amount of data about how households consume energy. Understanding these patterns helps energy suppliers plan demand and helps households find ways to reduce waste.

This project analyses minute-level electricity measurements from one household. The data has several electrical variables that are related to each other, so it is a good case for exploratory data analysis (EDA) and for Principal Component Analysis (PCA).

2. Research motivation and research questions

Household electricity data is large, and many of its variables measure related things. Before building any model, it is useful to check data quality, look at patterns over time and see whether the variables can be summarised with fewer dimensions.

Main research question: How do household electricity consumption patterns vary over time, and which electrical measurements contribute most to the variation in household energy consumption?

Supporting research questions:

  1. How does electricity consumption vary throughout the day and across different months?
  2. Which electrical measurements have the strongest relationships with each other?
  3. Are there unusual electricity consumption patterns or outliers?
  4. Which variables contribute most to the overall variation in electricity consumption?
  5. Can PCA reduce dimensionality while retaining most of the information?

3. Dataset description and source

The data is the Individual Household Electric Power Consumption dataset from the UCI Machine Learning Repository (Hebrail and Berard, 2012). It contains measurements from one house, recorded every minute between December 2006 and November 2010. The file is read from data_path below.

Variable Description Unit
Date Date of the measurement (dd/mm/yyyy) date
Time Time of the measurement (hh:mm:ss) time
Global_active_power Household global minute-averaged active power kilowatts
Global_reactive_power Household global minute-averaged reactive power kilowatts
Voltage Minute-averaged voltage volts
Global_intensity Household global minute-averaged current intensity amperes
Sub_metering_1 Kitchen (dishwasher, oven, microwave) watt-hours
Sub_metering_2 Laundry room (washing machine, tumble-dryer, refrigerator, lighting) watt-hours
Sub_metering_3 Electric water heater and air conditioner watt-hours

The file uses semicolons as separators and writes missing numeric values as ?. The data represents a single household, so the results describe this home and not households in general.

# Location of the data file

)

5. Data cleaning and preparation

The Date and Time columns are stored as text, so they are combined and converted to a date-time. Time features are then created for the later analysis.

# Names of the continuous measurement variables
num_vars <- c("Global_active_power", "Global_reactive_power", "Voltage",
              "Global_intensity", "Sub_metering_1", "Sub_metering_2",
              "Sub_metering_3")

# Combine Date and Time into one date-time column
power <- power %>%
  mutate(DateTime = dmy_hms(paste(Date, Time)),
         Date = dmy(Date)) %>%
  select(-Time)

# Check that all dates were parsed
sum(is.na(power$DateTime))
## [1] 0
range(power$DateTime)
## [1] "2006-12-16 17:24:00 UTC" "2010-11-26 21:02:00 UTC"
# Create time features
power <- power %>%
  mutate(Hour = hour(DateTime),
         Weekday = wday(Date, label = TRUE, week_start = 1),
         Month = month(Date, label = TRUE),
         Year = year(Date),
         Day_Type = if_else(Weekday %in% c("Sat", "Sun"), "Weekend", "Weekday"))

# Check the new columns
power %>% select(DateTime, Hour, Weekday, Month, Year, Day_Type) %>% head()

8. Outlier detection and treatment

# Random sample used for plots that are slow with the full data
set.seed(123)
power_sample <- slice_sample(power, n = 50000)
# Boxplots of each variable
power_sample %>%
  select(all_of(num_vars)) %>%
  pivot_longer(everything(), names_to = "Variable", values_to = "Value") %>%
  ggplot(aes(x = Variable, y = Value)) +
  geom_boxplot(fill = "lightblue", outlier.size = 0.5) +
  facet_wrap(~ Variable, scales = "free") +
  labs(title = "Boxplots of Electrical Measurements (random sample of 50,000 rows)",
       x = NULL, y = "Value") +
  theme_minimal() +
  theme(axis.text.x = element_blank())

# Count outliers using the 1.5 x IQR rule
count_outliers <- function(x) {
  q <- quantile(x, c(0.25, 0.75))
  iqr <- q[2] - q[1]
  sum(x < q[1] - 1.5 * iqr | x > q[2] + 1.5 * iqr)
}

outlier_table <- tibble(
  Variable = num_vars,
  Outliers = sapply(power[, num_vars], count_outliers)
) %>%
  mutate(Percent = round(100 * Outliers / nrow(power), 2))
